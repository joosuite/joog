# Joog brand assets

| Asset | Use |
| --- | --- |
| [logo.png](logo.png) | Full Joog wordmark for headers, documentation, and the sign-in page. |
| [icon.png](icon.png) | Joog icon for favicons and compact product icons. |

Both PNG files have transparent backgrounds. Preserve their aspect ratios:
2:1 for the wordmark and 1:1 for the icon. The brand color is cobalt `#3154ae`.
On dark backgrounds, the wordmark can appear in white.
